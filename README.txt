# Satyam Plylam Website

A fully responsive single-page HTML/CSS/JS website for Satyam Plylam, Jaipur.

## Included
- Responsive header + mobile menu
- Hero section
- About section
- Product/services section
- Project solutions
- Why choose us
- Premium brands
- Process
- Store gallery with lightbox
- Review slider
- Contact CTA
- Footer with GSTIN, address, phones and social links
- Floating WhatsApp, Call, Maps and Back-to-top buttons
- Scroll reveal animations, hover effects and counters
- Supplied Satyam Plylam logo/store/poster images
- Remote Unsplash interior/product imagery

## Important before going live
1. Replace the sample review cards with the business's verified Google reviews.
2. Confirm product/brand availability and exact current business details.
3. The remote interior images are loaded from Unsplash. For a production site, download/licence the images you want and place them in `assets/` if you want the website to work without external image requests.
4. Open `index.html` directly for a quick preview, or deploy the folder to Hostinger/Vercel/Netlify.
